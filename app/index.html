Clonelane

Get started

Clonelane keeps every clone of a repository in step. It never pushes, and it backs up every branch it moves.

    You're set. Open this guide again from Guide in the header.

    Add a workspace

    A group is one repository: put every clone and worktree of it in the same group. Sync and .env sharing work within a group.

    Apply fetches first and backs up every branch it moves. It never pushes or stashes.

    Saves this form to run again later: source, targets, kept keys and key options. With every target ticked, the profile follows the group, including workspaces added later. Only key names are saved, never values.

    Keys are copied only between workspaces in the same group. Only key names are shown, never values. Keys that exist only in a target are kept unless you choose to remove them; keys kept local in a target are never touched. Applying rewrites each target file without its comments.
